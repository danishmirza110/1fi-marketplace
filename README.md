# 1Fi Marketplace

This project was created as part of the **1Fi SDE Intern Assignment**.

The project adds a new **1Fi Marketplace** section to the Shop page. Users can browse products, view product details, select variants, choose an EMI plan, and continue with their selected plan.

## Features

- Product listing
- Search products
- Category filters
- Product details
- Product variants
- Product pricing
- EMI plan options
- EMI plan selection
- Order confirmation
- Loading states
- Error states
- Empty states
- Responsive design

## Shop Sections

The Shop page has three sections:

- Top Brands
- Nearby Stores
- 1Fi Marketplace

Top Brands and Nearby Stores are kept as placeholders.

The **1Fi Marketplace** section contains the complete product and EMI flow.
